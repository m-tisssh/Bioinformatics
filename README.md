# Лабораторная работа №1
Лаборторная работа состоит из двух файлов: preprocess.py (отвечает за предобработку) и compute_cosine.py  

Идея заключается в том, что мы берём целевую аминокислотную последовательность (target), сравниваем её со множеством кандидатов из fasta двумя метриками — (1) максимальный процент совпадений при переборе смещений (метод «скольжение») и (2) косинусное сходство частот аминокислот — и объединяем эти метрики в ТОП-10 рейтинг.

## Шаги выполнения:

1) Предобработка FASTA (preprocess_minimal_fast.py)
  - Загружаем белковые последовательности из .fasta.
  - По заданному target-header выбираем целевую последовательность (например, известный белок).
  - Для каждой другой последовательности вычисляется схожесть методом «скольжения» (быстрое вычисление совпадений при сдвигах).
  - Результаты (процент идентичности, количество совпадений, длина перекрытия и оптимальный сдвиг) сохраняются в TSV-файл.

2) Оценка сходства (compute_cosine_minimal.py)
  - Загружаем результаты предобработки (например, из файла test_preproc.tsv)
  - Рассчитывается косинусное сходство между целевой и каждой последовательностью (учитывается распределение аминокислот).
  - Итоговый балл ― это комбинация двух метрик: процент идентичности (метод скольжения), косинусное сходство (по составу аминокислот).

В результате получаем рейтинг наиболее похожих последовательностей и сохраняем данные в result.csv

## Запуск

шаг 1: предобработка
```
python preprocess.py --fasta uniprot_sprot.fasta --target-header "sp|Q6GZX4|001R_FRG3G" --out test.preproc.tsv
```
    
шаг 2: расчёт метрик
```
python compute_cosine.py --preprocessed test.preproc.tsv --top 10 --w-match 0.6 --w-cos 0.4 --out results.csv
```
